# ScreenTime RS v0.2.3 Build Notes

## Fixes

- Fixed the Applications Usage Time page so long application lists can scroll normally.
- Fixed Windows sign-in startup by using the per-user Run registry entry.
- Added a Settings-page control for enabling or disabling the same startup entry.
- Updated all project version references to v0.2.3.

## Validation

Build and runtime validation should be performed on Windows before tagging the release.


## v0.2.3 Changes

- Fixed usage-time cards being clipped when the main window is narrow.
- Added responsive card layout that switches from four columns to two or one column as space becomes limited.
- Fixed the Settings page shifting toward centered alignment when the window is enlarged.
- Kept Settings content explicitly left-aligned for consistent placement across window sizes.
