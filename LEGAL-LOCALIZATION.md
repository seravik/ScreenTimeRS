# Legal text localization

ScreenTime RS ships only the English Markdown legal documents:

- `TERMS.md`
- `PRIVACY.md`

The application embeds localized Simplified Chinese and Traditional Chinese copies for the in-app legal dialog so that the displayed text follows the selected UI language without shipping duplicate Markdown files.

The English Markdown files remain the canonical shipped legal documents for v0.9.0. If the legal text changes in a future version, update the corresponding embedded localized text at the same time.
