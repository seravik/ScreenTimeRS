# ScreenTime RS v0.7.2 Build Notes

- Delete-all-data confirmation button is disabled until the generated confirmation code matches exactly.
- The destructive action button uses a red style only when enabled; invalid or empty input remains unavailable.
- UI build intermediates (`ui/bin` and `ui/obj`) are cleaned before and after publishing.
- Inno Setup uses high LZMA2 compression settings for a smaller installer package.


## Dark mode dialog fix

- Data management dialogs now explicitly follow the resolved application theme in light and dark modes.


## Navigation resize stability

- Expanded the navigation resize hit zone and kept it stationary during captured dragging to prevent boundary hover flicker.
