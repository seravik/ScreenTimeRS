# Changelog

## v0.1.0 - 2026-09-14

Initial consolidated release.

### Fixed

- Bundled Noto Sans CJK SC and configured egui font fallback so Simplified Chinese UI text no longer renders as square boxes.

### Added

- Windows GUI.
- SQLite local storage.
- Today, yesterday, current-week and current-month totals.
- 14-day visual usage trend.
- Application usage ranking.
- Foreground application and window detection.
- Lock-state-aware usage collection.
- Monitor activity status.
- Real-time CPU and memory.
- System tray background mode.
- Windows login auto-start.
- Light/dark theme.
- Windows x64 GitHub Actions build.
- No-console release executable.

### Notes

Version number is intentionally locked to `v0.1.0` unless explicitly changed by the project owner.
