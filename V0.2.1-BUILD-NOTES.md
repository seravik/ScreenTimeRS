# ScreenTime RS v0.2.1 Build Notes

v0.2.1 is a bug-fix release based on the v0.2.0 WinUI 3 architecture. It focuses on eliminating live-refresh flicker and making application shutdown predictable.

## Architecture

- `src/main.rs`: Rust monitoring, SQLite persistence, foreground process detection, lock/activity detection, tray and background process.
- `ui/`: native WinUI 3 / Fluent UI frontend.
- The Rust process writes `snapshot.json` for the UI while keeping SQLite as the persistent database.

## Windows build

The current execution environment does not contain the Windows Rust/MSVC toolchain or .NET SDK, so the final Windows binaries cannot be compiled here. The repository contains the Windows build scripts and GitHub Actions workflow for the target environment.

Run on Windows:

```powershell
.\build-windows.bat
```

Then:

```powershell
.\build-installer.bat
```

Before publishing the release, verify:

1. `dotnet publish ui\ScreenTimeRS.UI.csproj -c Release -r win-x64 --self-contained true -p:WindowsAppSDKSelfContained=true` succeeds.
2. `cargo build --release` succeeds with the MSVC toolchain.
3. `ScreenTimeRS.UI.exe` starts the Rust collector and shows live statistics.
4. The tray menu opens the WinUI application instead of the old egui window.
5. `Firefox`, `explorer.exe`, `Code.exe`, etc. are presented with friendly names where Windows metadata is available.
6. Application icons render for executables that expose an associated icon.
7. Existing v0.1.0 SQLite data remains readable after the `exe_path` schema migration.
8. Windows startup launches the WinUI application and the collector continues in the background.

- fixed3: ensure the WinUI frontend always renders immediately; initialize snapshot before the first collector tick and make navigation select Overview after Loaded.

## 数据采集修复（fixed5）
WinUI 与 Rust 核心此前使用了不同的数据目录：Rust 使用 `ProjectDirs::data_dir()`（Windows RoamingAppData），而 WinUI 直接读取 LocalAppData，因此前端只能看到默认空快照。fixed5 已统一到 LocalAppData，并自动迁移旧数据库。

## v0.2.1 修复说明

- UI 页面改为持久实例并原地更新，避免每秒重建控件造成闪烁。
- 应用图标增加缓存，避免每秒重复提取图标。
- 概览状态 InfoBar 支持关闭按钮，并在实时刷新时保持关闭状态。
- 托盘“退出”通过共享 shutdown.flag 协调 UI 与 Rust collector，确保窗口和后台记录进程能够一起退出。

## v0.2.1 fixed4 repair
- WinUI snapshot/shutdown paths now point to the same `ProjectDirs::data_local_dir()` location used by the Rust collector: `%LOCALAPPDATA%\\ScreenTimeRS\\ScreenTime RS\\data`.
- Rust tray process now pumps the native Windows message queue on the same thread that owns the tray icon, so the context menu and menu events are delivered correctly.
- Version remains `0.2.1`.
